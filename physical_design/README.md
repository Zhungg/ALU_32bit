# Physical design (Cadence Innovus)

Place & route of the scan-inserted netlist `synthesis/dft_run/outputs/alu_top_syn_dft.v`
on gpdk045 / gsclib045, targeting the two modes defined in `scripts/mmmc.tcl`
(`FUNC_MODE`: 10 ns, `SCAN_MODE`: 50 ns; slow 0.9 V/125 °C for setup, fast 1.1 V/0 °C for hold).

## Contents

| Path | Description |
| :--- | :--- |
| `scripts/import.tcl` | Loads libraries, LEF, constraints and the netlist (`init_design`). Needs `source flow_config.sh` first. |
| `scripts/mmmc.tcl` | Multi-mode multi-corner setup (libraries, QRC RC corner, delay corners, views). |
| `scripts/alu32_cts_spec.tcl` | Clock-tree spec generated by Innovus for CCOpt. |
| `scripts/innovus_session_history.tcl` | **Recorded command history** of the full Innovus session (see below). |
| `scripts/rail_analysis/*.pp` | Power-pin files for VDD / VSS rail analysis. |
| `config/streamOut_*.map` | Layer maps for GDS stream-out and for Assura LVS. |
| `results/alu_top_postroute_drc_lvs{,_pg}.v` | Final post-route netlists (plain, and with PG pins for LVS). |
| `signoff/` | Curated signoff evidence (DRC, connectivity, placement check, antenna, power, setup/hold summaries). |

## Session history

The layout was built interactively. `scripts/innovus_session_history.tcl` is Innovus's own
record of that session, **not a clean batch script** — it contains experiments and ECO
retries. Use it to see exactly how each stage was done. Search for:

| Stage | Look for |
| :--- | :--- |
| Import | `read_mmmc`, `init_design` |
| Floorplan / pins | `create_floorplan`, `write_db results/alu32_pinassign.enc` |
| Power plan | `add_rings`, `add_stripes`, `route_special`, `connect_global_net` |
| Placement | `place_opt_design` |
| CTS | `ccopt_design` |
| Routing / opt | `route_design`, `opt_design -post_cts`, `eco_route` |
| Signoff checks | `check_drc`, `check_connectivity`, `timeDesign` |
| Fill / export | `add_fillers`, `write_stream` |

Host paths were replaced by `<PROJ_ROOT>` / `<HOME>`.
